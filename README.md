# 做菜助手

纯前端做菜管理网页，数据保存在浏览器 `localStorage` 中，不需要后端服务。

## 使用方式

直接用浏览器打开 `index.html`。

## 已实现功能

- 今日推荐：根据库存推荐菜谱，显示缺少食材和临期食材。
- 今日菜品：按餐次管理，支持进入步骤制作和计时。
- 菜谱：搜索、标签、难度、耗时、收藏筛选。
- 冰箱：管理食材库存和保质期。
- 购物清单：缺少食材一键加入，已购买项可入库。
- 做菜历史：制作完成后自动记录。
- 后台管理：食材分类、食材、菜谱增删改查。
- 菜谱图片：支持上传、预览、替换、删除。
- 备份恢复：支持导出、导入、复制备份文本和重置示例数据。

## 存储说明

第一版使用 `localStorage`。代码中通过统一的 `storage` 对象读写数据，后续接入数据库时可以替换该存储实现，尽量保持业务字段不变。
